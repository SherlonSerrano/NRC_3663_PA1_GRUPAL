# Sistema de Registro y Control de Productos

## Descripción

Programa en Java que permite registrar un producto, mostrar su información,
validar y controlar su stock mediante un menú por consola. Desarrollado como
parte de la evaluación PA1 del curso, aplicando fundamentos de POO: clases,
atributos, constructores, métodos y estructuras de control.

## Instrucciones de ejecución

1. Clonar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Ejecutar la clase `Main.java`.
4. Usar el menú por consola para registrar y gestionar el producto.

## Decisiones de diseño

- Se optó por manejar un único producto activo a la vez de acuerdo a lo avanzado hasta la sesión 3.

- Se incluyó un atributo de clase (`contadorProductos`) para mostrar la
  diferencia entre atributos de instancia y de clase.

- Se usó `do-while` para asegurar que el menú se muestre al menos una vez
  y `switch` para las opciones, por claridad frente a múltiples `if-else`.
